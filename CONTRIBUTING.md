# 🤝 Como Contribuir para o Quiz Kultivi

Fico muito feliz com o seu interesse em melhorar este projeto pedagógico! Para contribuir, siga os passos:

1. Faça um **Fork** deste repositório para a sua conta.
2. Adicione novas perguntas ou melhorias visuais respeitando a formatação atual do código.
3. Abra um **Pull Request** detalhando as melhorias que você implementou.
